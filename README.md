# 📅 Proyecto IHC: Sistema de Reserva de Espacios Coworking

## 👥 Integrante del Equipo
- Eduardo Castro Paredes


## 📝 Descripción del Proyecto
Diseño de interacción para una aplicación móvil orientada a la gestión eficiente de reservas de salas de reunión y espacios de coworking. El objetivo es solucionar problemas de visibilidad en tiempo real, conflictos de horario y falta de retroalimentación en entornos universitarios o corporativos.

Este repositorio contiene la documentación completa del proceso de diseño, desde el descubrimiento de requisitos hasta el prototipado de alta fidelidad, aplicando los conceptos de la Unidad 2 de Interacción Humano-Computador.

## 🎨 Prototipado y Evidencias

### Flujo de Usuario
El sistema sigue un flujo lineal optimizado para completar la reserva en menos de 4 pasos:
1. Inicio y Filtros.
2. Selección de Sala Disponible.
3. Detalle y Confirmación.
4. Éxito y Comprobante.

## 🤝 Acuerdos del Equipo
- **Metáfora Seleccionada:** "Agenda Compartida Digital", priorizando la gestión temporal sobre la espacial.
- **Enfoque de Diseño:** Eficiencia móvil (uso con una mano) y claridad en la retroalimentación.
- **Herramientas:** Uso de GitHub para versionamiento colaborativo y documentación iterativa.
